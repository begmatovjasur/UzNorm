# Xavfsizlik

- Server faqat `127.0.0.1`da ishlaydi. Uni `0.0.0.0`, tunnel yoki public hosting bilan ochmang.
- Oddiy matn so‘rovlari tashqi APIga yuborilmaydi va server logiga yozilmaydi.
- Model importi checksum, fayl tarkibi va parent/run bog‘liqliklarini tekshiradi; mavjud model bosib yozilmaydi.
- Tasdiqlanmagan model yoki pickle fayllarini qo‘lda ochmang; tekshiruvlarni o‘chirmang.
- Parol, API key, raw dataset yoki shaxsiy matnni issue/PRga joylamang.
- Muammo haqida minimal, shaxsiy ma’lumotsiz takrorlash misoli bilan xabar bering. GitHub private vulnerability reporting yoqilgan bo‘lsa, undan foydalaning; aks holda sezgir tafsilotlarni public issue’da yozmang.

Bu lokal tadqiqot ilovasi, autentifikatsiyali internet xizmati emas. Model javobidagi ma’no, nom va raqamlarni foydalanuvchi tekshirishi kerak.
